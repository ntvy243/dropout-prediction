# Data
`data.csv` is the UCI dataset **Predict Students' Dropout and Academic Success** (ID 697), semicolon separated, 4,424 students, 36 predictors, target `Target` (Dropout / Enrolled / Graduate).

- Source: https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success
- Citation: Realinho, V., Machado, J., Baptista, L., Martins, M.V. (2022). Predicting student dropout and academic success. *Data* 7(11), 146. https://doi.org/10.3390/data7110146
